# C Program to swap first and last digit of a number
The logarithm of a number is the exponent to which a base must be raised to obtain that number. Essentially, it's the inverse operation of exponentiation. For example, the log base 10 of 1000 is 3 because 10 raised to the power of 3 equals 1000. 

## Here's a more detailed explanation:
#Definition:
If x = b^y, then y = log_b(x). In other words, y is the logarithm of x to the base b. 
# Example:
If 10^2 = 100, then log_10(100) = 2. 
# Base:
The base is the number that is being raised to a power. Common bases include 10 (common logarithm, often written as log), and e (natural logarithm, often written as ln).
